03

주요 공적내용 · 공적개요서 최종 요약

분야마다 공적조서용 핵심 활동 2개와 공적개요서 마지막에 들어갈 한 줄 요약을 구분해 작성합니다.

AI 문장 다듬기는 선택사항입니다. 버튼을 눌렀을 때만 요청하며, 활동 분야·내용·일자·시간만 전송하고 이름·주소·연락처는 전송하지 않습니다.
공개 AI 서버 연결을 준비 중입니다.
키는 이 탭에만 임시 보관됩니다.
입력한 키는 브라우저 저장소에 저장하지 않습니다. 이 탭을 열어 둔 동안에만 메모리에 보관하고, AI 요청 때 Cloudflare 중계 서버를 거쳐 OpenAI로 전달합니다. API 이용료는 본인 계정에 청구됩니다.
API 키 발급·붙여넣기·사용방법

1. API 키 발급

  1. OpenAI Platform에 로그인합니다.
  2. API Keys 메뉴로 이동합니다.
  3. + Create new secret key를 누르고 키 이름, 프로젝트, 권한을 설정한 뒤 새 키를 만듭니다.
  4. 생성 직후 전체 키가 한 번 표시됩니다. Copy를 눌러 복사해 안전한 곳에 잠시 보관하세요. 창을 닫으면 전체 키를 다시 볼 수 없고, 키를 다른 사람에게 보내거나 공개하면 안 됩니다.

2. 이 앱에 키 붙여넣기

  1. 공적조서 앱으로 돌아와 AI 사용 방법 메뉴를 엽니다.
  2. 내 OpenAI API 키 사용을 선택합니다. 아래에 내 OpenAI API 키 입력 칸이 나타납니다.
  3. 입력 칸을 클릭한 뒤 키 복사할 때 사용한 키보드의 Ctrl + V를 눌러 붙여넣습니다. 마우스 오른쪽 버튼을 눌러 붙여넣기를 선택해도 됩니다.
  4. 이번 탭에서 사용을 누릅니다. 입력 칸이 비워지고 ‘사용 준비됨’이라고 표시되면 키가 앱 메모리에 준비된 것입니다.
  5. 엑셀 실적을 반영한 뒤 AI로 문장 다듬기를 누릅니다. 다른 키를 쓰려면 키 지우기를 누르고 새 키를 붙여넣으세요. 새로고침하거나 탭을 닫으면 키는 사라집니다.

API 결제는 ChatGPT 구독과 별도이며, OpenAI API 계정 사용량에 따라 비용이 발생합니다. 계정에 결제 수단이나 크레딧 설정이 필요할 수 있습니다. 키는 요청 중 Cloudflare 중계 서버를 거쳐 OpenAI로 전달되며 앱에 저장되지 않습니다.

API 발급 비용과 사용료 줄이는 방법
  1. 최초 최소 $5 충전은 API 잔액에 넣는 선불 크레딧입니다. 무료 토큰은 별도 프로그램으로, 자격이 되는 API 조직만 받을 수 있습니다.
  2. OpenAI 데이터 공유 설정에서 “You're eligible for free daily usage on traffic shared with OpenAI” 안내가 보이는지 확인합니다. 안내가 있고 입력·출력 공유에 동의하면, 대상 모델 사용에 무료 토큰이 자동 적용됩니다. 이 앱에서 사용하는 gpt-4o-mini도 대상 모델입니다.
  3. 무료 한도는 조직 등급에 따라 다릅니다. Build 등급은 소형 모델 묶음에서 하루 최대 250만 토큰, Launch·Grow 등급은 최대 1천만 토큰입니다. 자격이 없는 조직은 적용되지 않고, 한도를 넘는 사용은 정상 요금이 청구됩니다. API 잔액이 0보다 커야 합니다.
  4. 데이터 공유를 켜면 이 앱에서 OpenAI로 보내는 활동 분야·내용·일자·시간과 AI 답변도 공유되어 모델 품질 평가·향후 개선에 사용될 수 있습니다. 이름·주소·연락처 칸은 보내지 않지만, 활동 내용에 민감한 정보가 있으면 공유를 켜지 마세요. 설정은 조직 소유자가 관리하며 나중에 끌 수 있습니다.
  5. OpenAI Platform의 프로젝트 Limits에서 사용 한도와 알림을 낮게 설정하고, 결제 설정 중 Use auto-reload(자동 충전)는 원하지 않으면 끕니다.
  6. 이 앱은 엑셀을 넣을 때 AI를 자동 호출하지 않습니다. 실적을 확인한 뒤 필요할 때만 AI로 문장 다듬기를 누르고, 필요 없는 실적은 표에서 선택 해제하세요. 카드에 $5가 ‘승인 대기’로 보이는 것은 실제 크레딧 구매가 아닌 임시 승인일 수도 있습니다.

무료 토큰 대상 여부와 실제 사용량은 API 사용량에서 확인하고, 모델별 요금은 공식 API 가격표에서 확인하세요. ChatGPT 구독료와 API 사용료는 별도입니다.
