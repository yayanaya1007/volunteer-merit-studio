# 사업별 지도점검표 자동 작성

운영현황 `.xls`/`.xlsx`와 집행장부 `.xls`/`.xlsx`를 브라우저에서 읽어 사업 종류, 월별 운영비·집행액, 결제수단, 집행일, 거래처를 확인합니다. 자료를 서버로 보내지 않습니다.

## 실행

프로젝트 루트에서 `node server.mjs`를 실행한 다음 `http://127.0.0.1:8769/tools/budget-supervision/`을 엽니다. 운영현황 파일과 집행장부를 함께 선택하고 보고 기준 월을 고르면 결과가 자동으로 표시됩니다. 각 사업 카드의 **이 사업 HWPX 다운로드**를 누르면 지도점검 한글 서식을 내려받습니다.

## 처리 기준

- 운영현황과 집행장부는 달력 날짜를 맞추지 않고 월별 합계로 비교합니다. 운영현황 운영비는 운영현황의 활동 월, 집행액은 집행장부의 거래 월로 집계합니다.
- 보고 기간과 HWPX 세부 지출 날짜는 집행장부의 거래일 기준입니다. 사업 카드에서 문구를 적용할 지출 행 앞에 체크한 뒤 `재료 구매` 또는 `재료비 지급`을 고르면 체크한 행에만 프로그램명과 선택 문구를 넣습니다. 선택하지 않은 행은 집행엑셀 지출내용을 유지합니다. 프로그램명을 자료에서 하나로 정할 수 없으면 `프로그램명 확인 필요` 뒤에 선택 문구를 붙입니다.
- 각 사업 카드에서 비고에 넣을 `전문봉사단` 또는 `가족봉사단`을 고르고, 해당 세부 분야를 선택하면 선택 조합이 HWPX 세부 지출 표의 비고 칸에 들어갑니다. 전문봉사단은 `손뜨개`, `날세움`, `귀건강`, 가족봉사단은 `월드프랜드`, `논사니`, `달보드레`, `뚜기` 중에서 고릅니다. 선택 전에는 비고를 비워 둡니다.
- HWPX에는 집행장부에 적힌 날짜·금액·거래처·결제방법을 기록합니다. 프로그램명은 월 안에서 금액이 연결된 운영 내역에서 가져오며, 하나의 프로그램만 있는 달은 해당 이름을 사용합니다.
- 월 안에서 금액이 맞는 운영 내역이 있으면 결제방법 연결에 활용하지만, 일자는 연결 기준으로 사용하지 않습니다.
- 월별 집행 합계와 예산액은 장부의 실제 거래·배정 행으로 계산합니다.
- 거래처와 결제수단은 원자료에서 읽습니다. 확인되지 않는 값은 추정하지 않고 `자료 미확인`으로 표시합니다.
- 연결되지 않은 거래와 운영현황/장부 간 예산·금액 차이는 웹 화면에서 확인합니다. 해당 장부 거래는 HWPX에 남기며, 자동 대조 문구는 HWPX 비고 칸에 넣지 않습니다.
- 출력은 `templates/지도점검_사업별집행현황.hwpx` 패키지를 사용합니다. 원본 본문과 표 머리글·구조·스타일은 유지하고, 요청한 셀과 데이터 행만 작성하거나 필요한 행을 늘립니다.
