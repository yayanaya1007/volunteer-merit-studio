# 사업별 지도점검표 자동 작성

운영현황 `.xls`/`.xlsx`와 집행장부 `.xls`/`.xlsx`를 브라우저에서 읽어 사업 종류, 월별 운영비·집행액, 결제수단, 집행일, 거래처를 확인합니다. 자료를 서버로 보내지 않습니다.

## 실행

프로젝트 루트에서 `node server.mjs`를 실행한 다음 `http://127.0.0.1:8769/tools/budget-supervision/`을 엽니다. 운영현황 파일과 집행장부를 함께 선택하고 보고 기준 월을 고르면 결과가 자동으로 표시됩니다. 각 사업 카드의 **이 사업 HWPX 다운로드**를 누르면 지도점검 한글 서식을 내려받습니다.

## 처리 기준

- 운영현황과 집행장부는 달력 날짜를 맞추지 않고 월별 합계로 비교합니다. 운영현황 운영비는 운영현황의 활동 월, 집행액은 집행장부의 거래 월로 집계합니다.
- 보고 기간과 HWPX 세부 지출 날짜는 집행장부의 거래일 기준입니다. 사업 카드의 지출내역 표에서 전체 선택하거나 문구를 적용할 지출 행을 체크한 뒤 `활동재료 구매`, `활동재료비 지급`, `간식 구매`, `배너 제작` 또는 `현수막 제작`을 고르면 선택한 행에만 프로그램명과 선택 문구를 넣습니다. 선택하지 않은 행은 집행엑셀 지출내용을 유지합니다. 프로그램명을 자료에서 하나로 정할 수 없으면 `프로그램명 확인 필요` 뒤에 선택 문구를 붙입니다.
- 자동 지출내용은 운영현황 품목명과 집행장부 적요·지출내용·거래처에서 키워드를 찾아 분류합니다. `배너`는 `배너 제작`, `현수막`은 `현수막 제작`, `간식`과 `오거리할인매장`은 `활동 간식 구매`, 숫돌·뽁뽁이·수세미실·코바늘·기통석·에어캡·사포·아가한코엄마두코·아성다이소·동진종합철물건재·철물·웰빙엔라이프·핀셋은 `활동재료 구매`로 넣습니다. 개별 품목명과 거래처 이름은 분류 판단에만 사용하고 지출내용에는 넣지 않습니다. 거래처는 지출처 칸에 표시합니다. 자동 문구는 지출내용 칸에서 직접 고칠 수 있고, 화면에서 직접 선택한 문구가 자동 분류보다 우선합니다.
- 운영현황의 한 셀에 품목명과 금액이 여러 줄로 기록되어 있고, 여러 품목의 합계가 집행장부의 한 거래 금액과 일치하면 그 거래를 품목별 행으로 나누어 미리보기와 HWPX 세부 지출 표에 넣습니다. 여러 거래와 여러 품목의 합계가 일치하는 경우에도 금액 조합을 맞춰 나눕니다. 각 품목 행에서 `구매` 또는 `제작`을 따로 고를 수 있으며, 선택한 단어만 품목명 뒤에 붙입니다. 지출내용·지출처 칸은 직접 수정할 수 있고, 선택·수정한 내용은 저장한 작업과 HWPX에 반영됩니다. 합계가 맞지 않으면 자동으로 나누지 않고 원래 장부 거래로 표시합니다.
- 각 사업 카드에서 `전문봉사단` 또는 `가족봉사단`을 고른 뒤 세부 분야를 고르고, 적용할 지출 행을 체크해 `선택 행에 비고 적용`을 누릅니다. 비고에는 봉사단 종류를 제외한 세부 분야 이름만 화면 표와 HWPX 세부 지출 표에 표시됩니다. 전문봉사단은 `손뜨개`, `날세움`, `귀건강`, 가족봉사단은 `월드프랜드`, `논사니`, `달보드레`, `뚜기` 중에서 고릅니다. 적용 전에는 비고를 비워 둡니다.
- HWPX에는 집행장부의 날짜·거래처·결제방법을 기록합니다. 품목별 금액을 나눌 때는 운영현황에 적힌 세부 금액을 쓰며, 한 거래의 합계는 원래 집행장부 금액과 같습니다. 지출내용에는 운영현황의 프로그램명만 사용하며 봉사단체명은 넣지 않습니다.
- 월 안에서 금액이 맞는 운영 내역이 있으면 결제방법 연결에 활용하지만, 일자는 연결 기준으로 사용하지 않습니다.
- 월별 집행 합계와 예산액은 장부의 실제 거래·배정 행으로 계산합니다.
- 결과 화면의 `현재 작업 저장`을 누르면 원본 엑셀 파일과 보고 월, 지출내용·지출처의 수정값, 품목별 구매·제작 선택과 비고가 이 브라우저에 저장됩니다. `저장한 작업`에서 불러오거나 삭제할 수 있습니다. 저장본은 같은 기기와 브라우저에서만 사용할 수 있습니다.
- 거래처와 결제수단은 원자료에서 읽습니다. 확인되지 않는 값은 추정하지 않고 `자료 미확인`으로 표시합니다.
- 연결되지 않은 거래와 운영현황/장부 간 예산·금액 차이는 웹 화면에서 확인합니다. 해당 장부 거래는 HWPX에 남기며, 자동 대조 문구는 HWPX 비고 칸에 넣지 않습니다.
- 출력은 `templates/지도점검_사업별집행현황.hwpx` 패키지를 사용합니다. 원본 본문과 표 머리글·구조·스타일은 유지하고, 요청한 셀과 데이터 행만 작성하거나 필요한 행을 늘립니다.
