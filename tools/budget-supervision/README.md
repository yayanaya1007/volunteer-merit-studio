# 사업별 지도점검표 자동 작성

운영현황 `.xls`/`.xlsx`와 집행장부 `.xls`/`.xlsx`를 브라우저에서 읽어 사업 종류, 활동일, 운영비, 결제수단, 집행일, 집행액, 거래처를 자동 대조합니다. 자료를 서버로 보내지 않습니다.

## 실행

프로젝트 루트에서 `node server.mjs`를 실행한 다음 `http://127.0.0.1:8769/tools/budget-supervision/`을 엽니다. 운영현황 파일과 집행장부를 함께 선택하고 보고 기준 월을 고르면 결과가 자동으로 표시됩니다. 각 사업 카드의 **이 사업 HWPX 다운로드**를 누르면 지도점검 한글 서식을 내려받습니다.

## 처리 기준

- 날짜와 금액은 운영현황의 활동 내역과 집행장부 거래를 대조합니다. 운영일과 실제 결제일은 달라질 수 있어 14일 이내에 정확한 금액 합계가 맞는 거래를 연결하고, 날짜 차이를 결과에 표시합니다.
- 월별 집행 합계와 예산액은 장부의 실제 거래·배정 행으로 계산합니다. 보고 기간은 장부 거래일을 기준으로 자릅니다.
- 거래처와 결제수단은 원자료에서 읽습니다. 확인되지 않는 값은 추정하지 않고 `자료 미확인`으로 표시합니다.
- 연결되지 않은 거래와 운영현황/장부 간 예산·금액 차이도 감추지 않습니다. 해당 장부 거래는 결과 HWPX에 남기고 비고에 확인 상태를 씁니다.
- 출력은 `templates/지도점검_사업별집행현황.hwpx` 패키지를 사용합니다. 원본 본문과 표 머리글·구조·스타일은 유지하고, 요청한 셀과 데이터 행만 작성하거나 필요한 행을 늘립니다.
