# Volunteer Merit Studio

1365 봉사실적 엑셀과 CSV를 정리해 자원봉사 공적조서 HWPX 초안을 만드는 브라우저 웹앱입니다. 실적 파일과 입력 내용은 각 사용자의 브라우저 안에서 처리합니다.

## 실행

공개 사이트를 브라우저에서 열거나, 프로젝트 폴더에서 정적 파일 서버를 실행해 사용하세요. GitHub Pages에서는 한글 자동화 서버 없이 브라우저가 HWPX 초안을 생성합니다. 로컬에서 `node server.mjs`를 실행하면 설치된 한컴오피스 한글로 기존 서식을 적용할 수 있습니다. 두 방식 모두 엑셀과 작성 내용은 외부 서버로 전송하지 않습니다.

## 사용 흐름

1. 행사 정보와 추천 대상자의 인적사항을 입력합니다.
2. `.xlsx`, `.xls`, `.csv` 실적 파일을 선택합니다. 각 시트에서 활동분야, 봉사내용, 날짜, 시간, 승인상태 열을 찾아 읽고, 날짜 없는 요약 행을 상세 실적과 합치며 같은 날짜와 내용의 중복을 제외합니다.
3. 실적의 분야 분류, 승인 여부, 날짜와 시간을 확인하고 필요하면 직접 고칩니다.
4. 다섯 분야의 공적사항과 공적개요 한 줄 요약을 만들고 증빙자료에 맞게 수정합니다.
5. 공적요지와 현지조사 내용을 사실 확인 후 입력합니다.
6. 미리보기를 확인하거나 HWPX 초안을 저장합니다. 작업은 JSON으로 저장해 다시 불러올 수 있습니다.

## 양식과 확인 사항

브라우저 내보내기는 편집 가능한 HWPX 초안을 생성하며, 한글 COM 내보내기는 로컬 실행 시 기존 서식을 사용합니다. 문서에는 추천관 및 조사자 도장 이미지가 자동 삽입되지 않습니다. 저장 후 한글에서 빈 항목, 페이지 나눔, 표 모양과 서명 자리를 확인하세요. 품성, 지역 여론, 공적 일치 여부는 앱이 판단하지 않으며 담당자가 조사와 증빙자료를 확인해야 합니다.

## 개인정보 처리

실적 엑셀은 브라우저에서 읽고 작성 데이터는 외부 서버로 전송하지 않습니다. 공개 사이트는 정적 파일만 제공하며, 작업 저장과 문서 저장은 방문한 사람의 기기에서 다운로드됩니다.
