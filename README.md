# Volunteer Merit Studio

1365 봉사실적 엑셀과 CSV를 정리해 자원봉사 공적조서 HWPX 초안을 만드는 브라우저 웹앱입니다. 실적 파일은 브라우저에서 읽고, 승인 활동을 근거로 분야별 초안을 작성합니다.

## 실행

GitHub Pages 공개본은 브라우저에서 실적을 비교하고 기본 초안을 작성합니다. 정적 사이트라 AI 서버는 실행하지 않습니다. 이 PC의 프로젝트 폴더에서 `node server.mjs`를 실행해 `http://127.0.0.1:8769`를 열면 OpenAI AI 초안과 설치된 한컴오피스 한글의 문서 저장 기능을 사용할 수 있습니다. 로컬 AI는 `OPENAI_API_KEY` 환경변수 또는 Windows 자격 증명 관리자에서 `Volunteer Merit Studio - OpenAI API` 항목을 읽습니다. AI에는 활동 분야·내용·일자·시간만 전달하며 이름·주소·연락처는 전달하지 않습니다.

## 사용 흐름

1. **실적 엑셀 (필터 기준)**과 **시간인증 엑셀 (일자·시간)**을 각각 선택합니다. 시간인증 파일의 활동분야·내용이 실적 파일에 있고 승인 상태가 유효한 행만 남깁니다.
2. 포함된 실적의 자동 분류와 날짜·시간을 확인하고 필요하면 직접 고칩니다. 파일을 고르면 다섯 분야 기본 초안을 자동으로 채웁니다. 이 PC에서 로컬 서버로 앱을 열면 AI가 근거 있는 문장으로 초안을 다듬습니다.
3. 이름 등 엑셀에 없는 인적사항과 행사 정보를 입력합니다.
4. 다섯 분야 공적사항과 요약, 공적요지, 현지조사 내용을 증빙자료에 맞게 확인하고 수정합니다.
5. 미리보기를 확인하거나 HWPX 초안을 저장합니다. 작업은 JSON으로 저장해 다시 불러올 수 있습니다.

## 양식과 확인 사항

브라우저 내보내기는 편집 가능한 HWPX 초안을 생성하며, 한글 COM 내보내기는 로컬 실행 시 기존 서식을 사용합니다. 문서에는 추천관 및 조사자 도장 이미지가 자동 삽입되지 않습니다. 저장 후 한글에서 빈 항목, 페이지 나눔, 표 모양과 서명 자리를 확인하세요. 품성, 지역 여론, 공적 일치 여부는 앱이 판단하지 않으며 담당자가 조사와 증빙자료를 확인해야 합니다.

## 개인정보 처리

공개 사이트는 정적 파일만 제공합니다. 엑셀은 브라우저 안에서 비교하고 결과 파일은 이 기기에 다운로드합니다. 로컬 AI 초안을 실행하면 최소한의 승인 활동 정보가 OpenAI API로 전송되며, API 키는 로컬 Windows 자격 증명 관리자나 환경변수에서 읽습니다. API 키를 웹페이지 코드나 GitHub 저장소에 넣지 마세요.
