# Volunteer Merit Studio

작성용 엑셀 한 개 또는 1365 시간인증 원본 엑셀로 자원봉사 공적조서 HWPX 초안을 만드는 브라우저 웹앱입니다. 승인된 활동을 추려 총 봉사시간과 공적기간을 계산하고, 실제 활동을 기준으로 최대 5개 주제의 제목과 내용을 작성합니다. 공적 주제는 고정하지 않고 엑셀 활동분야와 봉사내용에서 도출합니다.

## 실행

GitHub Pages 공개본은 브라우저에서 실적을 비교하고 기본 초안을 작성합니다. 정적 사이트라 AI 서버는 별도로 배포해야 합니다. 로컬 서버는 이 PC에서 `node server.mjs`를 실행해 `http://127.0.0.1:8769`를 엽니다. 로컬 AI는 `OPENAI_API_KEY` 환경변수 또는 Windows 자격 증명 관리자에서 `Volunteer Merit Studio - OpenAI API` 항목을 읽습니다.

공개 AI 서버는 Cloudflare Worker로 배포합니다. 배포와 비밀값 설정은 [worker/README.md](worker/README.md)를 참고하세요. 공개 정적 페이지는 `api-config.js`의 `MERIT_API_URL`에 Worker 주소를 넣어 연결합니다. 사용자는 공개 페이지에서 접근 코드를 한 번 입력하며 코드는 현재 브라우저 탭의 세션에만 보관됩니다. API 키는 브라우저로 전송하지 않습니다. AI에는 활동 분야·내용·일자·시간만 전달하며 이름·주소·연락처는 전달하지 않습니다.

## 사용 흐름

1. **작성용 엑셀 양식 내려받기**를 누릅니다. 기본정보 시트에 한 사람의 인적사항을 입력하고, 시간인증 실적 시트 A1에 1365 엑셀 표 전체를 붙여 넣습니다.
2. 작성한 엑셀을 앱에서 **작성한 엑셀 불러오기 · 자동 작성**으로 올립니다. 인적사항과 승인된 실적을 함께 읽어 내용을 자동으로 채웁니다. 기존 1365 원본 파일만 바로 올려도 됩니다.
3. 공적 주제와 활동 제목은 실제 실적에 맞춰 최대 5개까지 나눕니다. 각 주제에는 활동 제목과 설명 세 줄을 작성합니다. 공적내용에는 참여 횟수·시간·활동일을 넣지 않습니다. 공적기간과 총 봉사시간은 별도 항목에 계산합니다.
4. AI 접근 코드나 개인 API 키를 연결한 경우, 엑셀을 불러올 때 AI 문장을 자동으로 적용합니다. 연결하지 않으면 기기 안에서 기본 초안을 작성합니다. 현지조사 확인내용은 해당 사람의 분야와 활동을 반영해 작성합니다. 사람마다 파일을 따로 작성하고, 웹앱에서 작업을 각각 저장하거나 JSON으로 내보낼 수 있습니다.
5. 입력 내용과 초안을 확인한 뒤 HWPX를 저장합니다. 원본 한글 서식을 그대로 렌더링한 미리보기는 한컴오피스가 설치된 로컬 앱에서 확인할 수 있습니다. 공개 GitHub Pages는 사용자 PC의 한글 프로그램에 접근할 수 없습니다.

## AI 서버 반영 주의

Cloudflare Worker가 이전 버전이면 `worker/src/index.js`의 수정 내용을 **다시 배포해야** 공개 사이트의 AI 주제 제목과 문장 다듬기에 반영됩니다. 재배포 전에도 작성용 엑셀 분석과 기본 공적내용 자동 작성은 AI 없이 사용할 수 있습니다.

## 양식과 확인 사항

브라우저 내보내기와 로컬 한글 내보내기는 제공된 원본 양식으로 편집 가능한 HWPX 초안을 생성합니다. 문서에는 추천관 및 조사자 도장 이미지가 자동 삽입되지 않습니다. 저장 후 한글에서 빈 항목과 서명 자리를 확인하세요. 품성, 지역 여론, 공적 일치 여부는 앱이 판단하지 않으며 담당자가 조사와 증빙자료를 확인해야 합니다.

## 개인정보 처리

엑셀은 브라우저 안에서 비교하고 결과 파일은 이 기기에 다운로드합니다. AI 초안을 요청하면 최소한의 승인 활동 정보가 OpenAI API로 전송됩니다. API 키를 웹페이지 코드나 GitHub 저장소에 넣지 말고, 백엔드 환경변수에만 보관하세요. 공유 접근 코드를 아는 사람은 AI 사용량을 쓸 수 있으므로 필요한 사람에게만 전달하고 유출 시 서버 비밀값을 바꾸세요.
